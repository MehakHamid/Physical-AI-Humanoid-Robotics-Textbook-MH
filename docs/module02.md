# Module 2: The Digital Twin (Gazebo & Unity)

**Focus: Physics simulation and environment building.**

## Key Topics
- Simulating physics, gravity, and collisions in Gazebo.
- High-fidelity rendering and human-robot interaction in Unity.
- Simulating sensors: LiDAR, Depth Cameras, and IMUs.

## Weekly Breakdown (Weeks 6-7: Robot Simulation with Gazebo)
- Gazebo simulation environment setup  
- URDF and SDF robot description formats  
- Physics simulation and sensor simulation  
- Introduction to Unity for robot visualization  

## Gazebo SDF Example
A basic Gazebo world definition file:

\`\`\`
# training_world.sdf
World contains:
1. Sun model for lighting
2. Ground plane
3. Simple robot model with box collision
\`\`\`

## Unity Integration
Unity provides high-fidelity rendering for:
1. Realistic human-robot interaction scenes
2. Visual feedback for training
3. Multi-modal simulation environments

## Sensor Simulation
- **LiDAR**: 360-degree distance scanning
- **Depth Cameras**: 3D perception
- **IMUs**: Inertial measurement for balance

## Learning Objectives
1. Set up Gazebo simulation environments
2. Create URDF/SDF robot models
3. Simulate sensors and physics
4. Integrate Unity for visualization
